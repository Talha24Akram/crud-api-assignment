Build a small REST API in Python using FastAPI that manages a to-do list of tasks.

Requirements:
- Store tasks in memory only (a plain Python list), pre-seeded with 3 example tasks. Each
  task has an integer id, a string title, and a boolean done (default false).
- Implement these five endpoints:
  - GET /tasks - return the full list of tasks
  - GET /tasks/{id} - return a single task, or a 404 with a JSON error body if the id
    doesn't exist
  - POST /tasks - create a new task from a JSON body containing "title". Assign the next
    free id automatically, default done to false, return the created task with a 201
    status. If title is missing or blank, return 400 with a JSON error body.
  - PUT /tasks/{id} - update a task's title and/or done from the JSON body. Return the
    updated task. 404 if the id doesn't exist.
  - DELETE /tasks/{id} - remove a task and return 204 with an empty body. 404 if the id
    doesn't exist.
- Also add GET / returning basic API info as JSON, and GET /health returning a simple
  status object.
- I want interactive API documentation available without extra setup.
- Use single-file code (main.py), no database, no external services.
